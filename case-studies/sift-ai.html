Sift AI — Document Intelligence

Problem

Document answers are difficult to trust when readers cannot inspect their sources. Sift AI makes the retrieval evidence visible alongside an extractive answer.

Architecture

Local file text → passage chunks → normalized query tokens → keyword-overlap ranking → top three evidence passages → answer assembled from the top two. The browser holds the passage array in memory; no backend, embeddings, vector database, or language model is used.

Query tokens are unique lowercase alphanumeric words of at least three characters. Each passage score is matched query tokens divided by query-token count. Uploaded files smaller than 1.5 MB contribute at most eight roughly 420-character chunks per file.

Try the demo

  1. Download the source repository and open index.html in a modern browser; no installation or API key is needed.
  2. Choose “How do we reduce response latency?” from the sample questions. Inspect the Engineering handbook passage and the answer about caching, background jobs, and p95 latency.
  3. Ask “zzzzunmatchedtoken” to see the no-evidence state. Upload a short .txt file containing “Orchard systems cache telemetry.” and ask “orchard” to inspect the uploaded source.

Outcomes

The implementation exposes ranked passages, their source names, and keyword-match scores, and gives a no-evidence response for an unmatched query. This demonstrates an inspectable retrieval workflow; no retrieval-quality benchmark or user-impact measurement is recorded.

Current limits

The evidence indicator is a heuristic, not calibrated confidence. Retrieval uses English-oriented tokens and cannot infer semantic similarity. File content is read as text, with a size cap and truncation; PDF parsing and production document permissions are future work. Uploaded content is rendered through HTML templates, so use trusted demo files only.

Next engineering step

Evaluate retrieval against labeled questions, render imported text safely, then add embeddings and grounded generation with document permissions.
