Research Desk

Problem

Research notes often disagree, but a generic answer hides the disagreement and its sources. Research Desk keeps source excerpts, provenance and a request trace beside each result.

Architecture

Text sources → bounded line-aware passages → Unicode tokens → BM25 ranking → up to six source excerpts. Optional AI synthesis returns a schema-checked brief; every claim must reference a supplied evidence ID.

All three workspaces share a Python backend, bounded context and execution traces. Browser storage saves sources and results; provider credentials stay on the server.

Verified outcomes

Browser-verified evidence search exposes both launch plans. Checks cover no-evidence abstention, Unicode, provenance and rejection of invalid model citations.

The shared backend passes 17 regression checks. These authored fixtures are not a general accuracy or user-impact benchmark.

Current limits

The public preview provides lexical search and extractive evidence. Successful model synthesis remains unverified because the provider account reported exhausted API credit. Citation IDs are validated; semantic claim support still needs review. No PDF parser, embeddings or shared team storage.
